# Chinese Spring Festival PM2.5 methods

This repository contains the analysis code used in the revised manuscript on firework-related PM₂.₅ during the Chinese Spring Festival and its association with online attention to drone shows.

The workflow is organized from data processing and exposure construction to the global XGBoost baseline, spatial analysis, GWR and pooled OLS.

## Code files

| File | Function |
|---|---|
| `00_nlp_xiaohongshu_analysis.ipynb` | Processes Xiaohongshu posts, identifies drone-show-related event records and constructs the online-attention exposure variables. |
| `00_xgboost_firework_masking.py` | Fits the global spatiotemporal XGBoost model, constructs the model-predicted reference concentration and estimates festival-period excess PM₂.₅. It also contains the nested 10-fold cross-validation routine. |
| `01_moran_updated_B.py` | Calculates annual Global Moran’s I using the updated festival-window data. |
| `02_lisa_updated_B.py` | Calculates Local Moran’s I/LISA classifications and produces the annual cluster maps. |
| `03_gwr_annual_firework.py` | Estimates annual GWR models for 2023 and 2024 with firework-related excess PM₂.₅ as the outcome. |
| `04_gwr_diagnostics.py` | Performs GWR diagnostics, residual Moran’s I, bandwidth sensitivity and kernel sensitivity analyses. |
| `05_ols_pooled_2023_2024.py` | Estimates pooled city-year OLS models with year-specific online-attention associations. |
| `06_ols_window_split.py` | Estimates the window-specific OLS models for 00:00–03:00 and 20:00–23:00. |

## Recommended workflow

Run the analyses in the following order:

1. Run `00_nlp_xiaohongshu_analysis.ipynb` to construct the event and online-attention variables.
2. Run `00_xgboost_firework_masking.py` to generate the model-predicted reference concentrations and festival-period excess PM₂.₅.
3. Run `01_moran_updated_B.py` and `02_lisa_updated_B.py` for global and local spatial autocorrelation.
4. Run `03_gwr_annual_firework.py` and `04_gwr_diagnostics.py` for the annual GWR analyses and diagnostics.
5. Run `05_ols_pooled_2023_2024.py` and `06_ols_window_split.py` for the pooled and window-specific panel regressions.

The downstream spatial and regression scripts use the files generated by the XGBoost step and the city-level covariate files.

## NLP processing

The NLP notebook processes Xiaohongshu posts using the study keyword dictionary and scoring rules, removes duplicate or syndicated records, aggregates the classified records to the city-event level, and constructs the online-attention measure used in the 2023–2024 spatial and regression analyses.

A manual audit of 418 observations from the 2025 Spring Festival period was used to assess event-occurrence classification. This validation concerns event classification and does not independently establish that post counts measure event intensity or firework substitution.

## Global XGBoost model

The XGBoost script fits one global spatiotemporal model to pooled hourly observations from all study units. It does not fit a separate geographically weighted XGBoost model for each prediction point.

The model uses meteorological, temporal, lagged PM₂.₅, rolling PM₂.₅ and city-indicator features. In the firework-window-masked specification, PM₂.₅ observations in the predefined firework windows are masked only in the auxiliary series used to construct lagged and rolling predictors; the observed PM₂.₅ values remain the response variable.

The predefined firework windows are:

- 00:00–03:00 on the relevant festival dates;
- 20:00–23:00 on the relevant festival dates.

Model performance is evaluated using nested 10-fold cross-validation. In each outer fold, an inner validation subset is used for early stopping, while the held-out outer fold is used only once for final evaluation. Performance is summarized using RMSE, MAE and R².

The positive observed-minus-reference residual during the festival window is used as the model-estimated festival-period excess PM₂.₅. This quantity is interpreted as an excess measure and is not treated as a uniquely identified causal contribution from fireworks.

Before running the XGBoost script, update `DATA_PATH` and the output paths to match the local data directory. The default path in the supplied script points to the original local data location.

## Spatial and regression models

Global and local Moran’s I use the updated festival-window city-level data and row-standardized Queen contiguity weights where available. LISA results are reported as descriptive spatial clustering patterns.

The annual GWR models are estimated separately for 2023 and 2024. The exposure is `ln(1 + Records)` followed by within-year standardization. Population density, green space and nighttime-light intensity are included as standardized covariates. An adaptive Gaussian kernel is selected by minimizing AICc over 20 to N nearest neighbours. Local significance is assessed using the multiplicity-adjusted critical t-value. Residual spatial dependence is evaluated with eight-nearest-neighbour spatial weights, and alternative bandwidths and an adaptive bisquare kernel are used for sensitivity analysis.

The pooled OLS models cover 2023–2024, use city-clustered standard errors and include a 2024 year indicator. The window-specific models use the same covariates and separate the festival period into 00:00–03:00 and 20:00–23:00.
